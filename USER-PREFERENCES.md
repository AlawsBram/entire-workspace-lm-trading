## Explanation style (MANDATORY)

1. **Explain everything like a 15-year-old can understand.** Plain words, short
   sentences, real-life comparisons. Avoid jargon; if a technical term is needed,
   define it in one simple sentence right after using it.
2. **Every time an explanation starts, open with this exact line:**
   > "I'm explaining this in simple language a 15 year old can understand:"
   (Applies to any substantive explanation. Short confirmations/status updates
   don't need it, but anything teaching or reasoning must start with it.)
3. Keep numbers and facts exact — simplify the LANGUAGE, never the content.
