# entire-workspace-lm-trading

Full research workspace for prediction-market trading (Polymarket, Kalshi, Hyperliquid): strategy notes,
backtests, bots, docs snapshots and the Hong Kong weather bot.

**Not included on purpose:**
- the decompiled Polymarket Android app (it is Polymarket's own copyrighted code), and
- any keys, wallets or `.env` files (only `.env.example` templates are here).

Third-party code keeps its own license (e.g. `PolyWeather/` is AGPL-3.0).
Nothing here is financial advice; most strategies in these notes were tested and found to have **no edge**.
